**Status: templates only. No sources have been collected.**

## Goal

At least **20 unique scholarly references** by the paper deadline. Aim for 25 to 30 candidates so some can be dropped. Everyone adds sources **every week**, starting now.

## Rules

1. **Open every source** and confirm it exists before adding it. Do not add anything from memory or from an AI answer.
2. Record the DOI or URL so someone else can find it.
3. Use scholarly sources: peer-reviewed papers, conference papers, books, standards. Add a few official documentation pages for tools if needed, but they do not count as scholarly references.
4. Each source is counted once. Check for duplicates.
5. Note which section of the paper you might use it in.
