## Demonstration plan

1. Show an original file: MATCH.
2. Show an exact copy: MATCH.
3. Show a modified copy (hashed only, never loaded): CHANGED.
4. Show an unknown run or stage: NO RECORD.
5. Optionally show an unauthorized registration being rejected.

## Backup demonstration (required)

- A screen recording of a full successful run, stored in shared storage **and** on a local laptop.
- Screenshots of each of the outcomes.
- Saved terminal output.
- A written fallback script ("If the live demo fails, say this and play the recording").
- Everything must work **without internet**.

## Slide rules

- Every number on a slide comes from `results/`.
- Do not claim more than the evidence shows.
- Cite the dataset source on a slide.
