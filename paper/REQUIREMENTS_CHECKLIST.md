# Paper Requirements Checklist

A box is checked only when the check passes and evidence is linked. Reviewer: Shabach (Chris is the paper owner).

## Assignment requirements

- [ ] Paper is 8 to 10 pages. *Evidence:* page count in the final Word file
- [ ] Uses the official IEEE conference template in Word. *Evidence:* template source link
- [ ] At least 20 unique scholarly references. *Evidence:* `research/sources.csv` count
- [ ] Every reference was opened and confirmed to exist. *Evidence:* "opened_and_confirmed_by" filled for each
- [ ] References formatted in IEEE style and cited in the text
- [ ] Similarity below 20 percent. *Evidence:* similarity report (tool and date)
- [ ] No AI-generated text in the submitted paper. *Evidence:* each author confirms in `research/contribution_log.csv`
- [ ] Paper submitted as a Word file
- [ ] PowerPoint submitted
- [ ] One designated person submitted both before **Nov 16, 2026, 11:59 p.m.** *Evidence:* confirmation saved

## Content checks

- [ ] Describes completed-game classification, not forecasting
- [ ] Explains that a MATCH does not prove accuracy, fairness, explainability, or data trustworthiness
- [ ] States that the blockchain is a local practice chain
- [ ] All results come from `results/` CSV rows
- [ ] Accuracy reported honestly, including with a baseline
- [ ] Gas reported in units, not dollars
- [ ] Ethics, privacy, transparency, limitations, future work, and conclusion included
- [ ] Dataset attribution and usage terms included
- [ ] Abstract written last and consistent with the final results
- [ ] Figures and tables numbered, captioned, and readable
- [ ] Each author read the whole paper once and checked their own technical claims

## Final reads

- [ ] Someone other than the author checked each section
- [ ] Spell-check and page-fit check done after final edits
- [ ] Final file stored in shared storage with a link recorded in `docs/PROGRESS.md`
